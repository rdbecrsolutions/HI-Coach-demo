# HI-Coach · Anteprima del portale

Anteprima statica del portale web di HI-Coach, con dati sintetici. Non è il sito reale: non ci sono account, pagamenti né dati di atleti o coach.

- [Vetrina](https://rdbecrsolutions.github.io/HI-Coach-demo/)
- [Pagina gara di prova](https://rdbecrsolutions.github.io/HI-Coach-demo/gara/maratona-sintetica-di-prova/)

Generata dal prototipo del portale nel repository HI-Coach. Sono incluse le viste demo per [runner](https://rdbecrsolutions.github.io/HI-Coach-demo/demo/runner/), [coach](https://rdbecrsolutions.github.io/HI-Coach-demo/demo/coach/), [promotore eventi](https://rdbecrsolutions.github.io/HI-Coach-demo/demo/promoter/) e [admin](https://rdbecrsolutions.github.io/HI-Coach-demo/demo/admin/), oltre alle schede dei coach sintetici. Login e azioni non sono attivi: non inserire credenziali reali. Workout, metriche, commenti, Spinta e messaggi mostrati sono dati fittizi; queste pagine sono pubbliche, `noindex` non è un controllo d'accesso. I conteggi dei giorni sono fissi alla data di generazione e gli indirizzi delle card/coach sintetici sono stabili.
